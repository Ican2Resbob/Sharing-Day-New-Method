What Is an Algorithm?

An algorithm is a sequence of logical, clear, and finite steps used to solve a problem.

? Problem
</> Algorithm steps
✓ Solution

Algorithm + programming language = program. The algorithm is the plan; the program is the plan written for a computer.

Five characteristics of a good algorithm

1

Input

Zero or more inputs

2

Output

At least one result

3

Definiteness

Clear steps, no vague words

4

Finiteness

Must stop, no endless loops

5

Effectiveness

Every step can be carried out

Three Ways to Write an Algorithm

Example: area of a rectangle (length × width)

01 Narrative

Everyday language, numbered steps. + easy for anyone. − can be ambiguous and long.

02 Pseudocode

READ width
area ← length * width
PRINT area

+ concise, close to code. − needs its own writing rules.

Understanding Variables and Data Types

age 16 Integer

A variable is a named storage box in memory. Its content can be replaced.

  • "16" (text) is not 16 (number)
  • In JavaScript, "5" + "5" gives "55", not 10
  • Naming: finalScore / final_score ✓   final score ✗
